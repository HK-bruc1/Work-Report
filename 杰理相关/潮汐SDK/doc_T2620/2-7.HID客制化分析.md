# 2-7. HID 客制化分析

## 1. HID 是什么

HID（Human Interface Device，人机接口设备）规范用于描述设备与主机之间的交互，可以描述键盘、鼠标、游戏控制器、传感器等不同设备。本文只讨论 HID 键盘。

HID 为键盘按键定义了标准编号，称为 Usage。键盘上报这些编号，电脑再根据操作系统、键盘布局和当前软件决定执行什么操作。

例如，设备上报 Ctrl+C，编辑器可能执行复制，终端可能执行中断进程。键盘上报的是键值，具体业务由电脑解释。

## 2. HID 键盘包括哪些部分

从按键功能看，常见键盘可以分为以下几部分：

| 部分 | 包含的按键 | 说明 |
|---|---|---|
| 字母、数字和符号区 | A～Z、0～9、标点符号 | 用于文字输入，最终字符受键盘布局和输入法影响 |
| 基本控制键 | Enter、Escape、Backspace、Tab、Space | 输入、取消、删除、缩进等常用操作 |
| 修饰键 | 左右 Ctrl、Shift、Alt、GUI | 与其他键组合；GUI 常对应 Windows 键或 Command 键 |
| 功能键 | F1～F24 | 都有标准键值，普通键盘通常只提供 F1～F12 |
| 编辑和导航键 | Insert、Delete、Home、End、Page Up、Page Down、方向键 | 编辑和光标移动 |
| 数字小键盘 | 小键盘数字、加减乘除、Enter、Num Lock | 与主键区数字键有不同的标准编号 |
| 其他标准键 | Caps Lock、Print Screen、Scroll Lock、Pause、国际／语言键等 | 根据键盘布局和产品用途选用 |
| 多媒体等扩展功能 | 音量、静音、播放／暂停、亮度等 | 常使用 HID 的 Consumer Control 定义，与普通键盘键值分属不同类别 |

键盘还可以接收电脑发来的状态，例如控制 Num Lock、Caps Lock 指示灯。设备是否提供这些灯，同样由产品设计决定。

## 3. 哪些键是所有厂商必须提供的

**HID 并没有要求每个键盘都必须提供一套完整的实体按键。标准定义的是按键如何表示，不是每个产品必须做多少个键。**

因此，以下产品都可以采用 HID 键盘方式工作：

- 带数字小键盘的完整键盘。
- 没有数字小键盘或独立功能键的紧凑键盘。
- 只有几个按键的快捷键设备，例如我们的五键设备。

厂商必须遵守的是：**声明并使用某个标准键值时，按标准格式上报，让主机按该标准键解释。** 例如，发送标准 F13 键值，主机就会把它作为 F13；不能要求通用键盘驱动直接将它理解为“开始翻译”。

因此需要区分：

| 项目 | 是否由厂商决定 |
|---|---|
| 产品上是否提供 F1、F13、数字小键盘等实体键 | 是，由产品设计决定 |
| 标准 F1、F13 等键值在 HID 中代表哪个键 | 否，由 HID 标准定义 |
| APP 收到 F13 后执行什么业务功能 | 是，可以由 APP 定义 |

## 4. 哪些部分可以自定义

### 4.1 自定义实体键与标准键值的映射

厂商可以决定一个实体键发送哪个标准键值或组合键。例如：

| 实体键 | 上报内容 |
|---|---|
| KEY1 | F13 |
| KEY2 | Ctrl+C |
| KEY3 | Enter |

键的位置、数量、外观和映射可以自定义，发送的键值仍遵循标准。

### 4.2 用 F13～F24 绑定自己的软件功能

**F13～F24 是标准功能键，不是专门留给厂商的私有键。** 只是常见键盘没有这些实体键，也没有跨所有软件统一的默认功能，因此适合用来绑定少量自定义操作。

例如：

```text
KEY1 → 上报 F13 → PC APP 监听 F13 → 执行“开始翻译”
```

这种方式不需要让固件理解“开始翻译”。固件只保存并上报 F13，业务功能保存在 PC APP 中。

需要注意：其他软件也可能使用 F13～F24，因此要检查快捷键冲突；自家 APP 或后台程序需要运行，才能执行它定义的功能。

### 4.3 使用真正的厂商自定义 HID 用途

HID 还提供 Vendor-defined Usage Page，范围是 `0xFF00～0xFFFF`，允许厂商定义自己的报告内容，由配套软件解释。

这不是往普通键盘键值里随便填一个“没用过的数字”，而是需要另外定义报告格式，并让 PC APP 按约定读取。标准键盘页里标为 Reserved 的值也不等于厂商可自由使用的键值。

对于我们的少量自定义功能，优先使用 F13～F24 绑定 APP 功能即可；真正的私有报告属于后续扩展，当前配键协议不能直接表达。

## 5. F1～F12 上的音量、亮度图案是什么

这些图案通常表示同一个实体键的另一种功能。键盘通过 Fn 或 Fn Lock 切换，让它发送普通 F 键，或者发送图案对应的功能。

例如，同一个键可以发送 F2，也可以发送音量降低。音量、静音、播放等通常已有标准 HID 定义，厂商主要决定把它们安排在哪个实体键上，并不一定是在创造私有键值。

如果图案对应厂商专属功能，则可能需要配套软件处理；如果对应键盘自身的灯效，也可能完全由键盘内部执行。
