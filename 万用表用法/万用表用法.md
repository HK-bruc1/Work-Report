# 测量脚位高低电平

**开发板使用万用表测电压时，选择直流电压档（V⎓），不是交流档（V~）。**

原因是开发板上的电源和信号都是直流：

- 开发板供电：
  - 3.3V
  - 5V
  - 12V（部分板子）
     → 都是**直流电压**
- GPIO 高低电平：
  - LOW：接近 0V
  - HIGH：例如 3.3V 或 5V
     → 也是**直流电压**

测量接法：

```
万用表黑笔（COM）  ─── 开发板 GND
万用表红笔（VΩ）   ─── 要测的引脚
```

档位：

```
选择：V⎓  （直流电压）
不要选择：V~ （交流电压）
```

比如 STM32：

- 测 3.3V 电源：
  - 黑笔 → GND
  - 红笔 → 3V3
  - 显示约 3.3V
- 测 GPIO：
  - GPIO 输出高 → 约 3.3V
  - GPIO 输出低 → 约 0V

如果你的万用表没有明显的 `V⎓`，一般标识可能是：

- `V---`
- `V⎓`
- `DCV`
- `V` 旁边一条实线和虚线

这些都是直流电压档。你看到的 **V 带波浪线 `V~` 是交流档**，不要用于测开发板逻辑电平。

# 测量脚位上下拉

用万用表可以**判断一个 GPIO 有没有被上拉/下拉，以及大致判断是强上拉还是弱上拉**，但要注意：万用表只能测“最终电压状态”，不能直接告诉你寄存器里的 Pull-Up/Pull-Down 配置。

### 1. 最基本的测法

万用表设置：

**V⎓ 直流电压档**

接线：

```
黑表笔 → GND
红表笔 → 要测试的 GPIO
```

然后观察 GPIO 电压。

### 2. 判断上拉

假设 MCU 是 **3.3V 系统**。

如果这个 GPIO 配置为输入，并且存在上拉：

```
3.3V
 │
[上拉电阻]
 │
 GPIO ───── 万用表红笔
 │
 MCU
```

此时测量：

**GPIO ≈ 3.3V**

例如：

- 3.25V
- 3.30V
- 3.28V

说明这个脚被拉向高电平，**可能存在上拉**。

### 3. 判断下拉

如果存在下拉：

```
GPIO
 │
[下拉电阻]
 │
GND
```

测量：

**GPIO ≈ 0V**

例如：

- 0V
- 0.01V
- 0.05V

说明这个脚被拉向低电平，**可能存在下拉**。

### 4. 最关键：怎么确认到底有没有上下拉？

仅仅测到 3.3V 或 0V，**不能完全确定**。

例如 GPIO 输出高电平：

```
GPIO = 3.3V
```

你不能据此判断它是：

- GPIO 输出 HIGH
- 内部上拉
- 外部上拉电阻

所以建议这样测试：

**第一步：确认 GPIO 设置为输入（最好设置为 High-Z / 浮空输入）**

然后测：

| GPIO状态    | 测量结果        | 判断           |
| ----------- | --------------- | -------------- |
| 输入浮空    | 电压乱飘/不稳定 | 可能没有上下拉 |
| 输入 + 上拉 | 接近 3.3V       | 有上拉的可能   |
| 输入 + 下拉 | 接近 0V         | 有下拉的可能   |

### 5. 如果你是在调试 MCU，我更推荐这个方法

如果你可以修改程序，可以做一个非常直观的实验：

**测试内部上拉：**

```
GPIO → Input Pull-Up
```

万用表：

```
黑笔 → GND
红笔 → GPIO
```

应该看到：

**≈ 3.3V**

然后改成：

```
GPIO → Input Pull-Down
```

应该看到：

**≈ 0V**

最后改成：

```
GPIO → Floating / No Pull
```

如果没有外部电路连接，这时候电压可能会**漂浮、不稳定**。

------

### 6. 还有一个很重要的办法：断电测电阻

如果你想判断**板子上有没有外部上下拉电阻**，可以：

**先给开发板断电！**

万用表切换到 **Ω 电阻档**：

```
测 GPIO ↔ GND
```

以及：

```
测 GPIO ↔ VCC
```

例如发现：

```
GPIO ↔ VCC ≈ 10kΩ
```

很可能板上有一个 **10kΩ 上拉电阻**。

如果：

```
GPIO ↔ GND ≈ 10kΩ
```

很可能是 **10kΩ 下拉电阻**。

不过这里要特别小心：**GPIO 连接着 MCU 内部电路、外围 IC、LED、按键等，直接测电阻不一定能准确得到某一个电阻的阻值**。
